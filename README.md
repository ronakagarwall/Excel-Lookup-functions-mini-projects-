# 🔍 Excel Lookup Functions Mini Projects

A collection of mini projects showcasing the practical use of Excel lookup functions for data retrieval, analysis, and reporting.

---

## 📦 Small Data Lookup

### Overview
Used lookup functions to retrieve product details such as product name, category, and price from a master product database.

### Skills Demonstrated
- VLOOKUP
- HLOOKUP
- Data Retrieval
- Table Referencing
- Excel Formula Application


## 🏏 IPL Judge Dashboard

### Overview
Applied lookup functions and Excel formulas to retrieve and organize cricket team performance data for analysis and reporting.

### Skills Demonstrated
- VLOOKUP
- Data Analysis
- Formula-Based Reporting
- Spreadsheet Organization

## 🛠️ Tools Used

`Microsoft Excel` `VLOOKUP` `HLOOKUP` `Data Analysis` `Spreadsheet Management`
